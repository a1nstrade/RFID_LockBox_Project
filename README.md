# RFID Lock Box

This project is going to be a Lock Box that will function with RFID authentication using an Arduino Uno.

This system will be used to detect authorized cards or tags and a servo motor to control the auto-locking of the mechanism. The LCD Display will be used to tell the user whether they have access or not.

# - Objectives

- Make an RFID authentication system using Arduino
- Control the locking mechanism electronically with a motor
- Display access status through the LCD Display
- Put the components into a functional lock box
- Build a big enough lock box to fit components and item(s)
- Test and prove the reliability of the system

# - Hardware

- Arduino Uno
- RFID reader and RFID cards
- Servo motor
- 16×2 LCD display
- Breadboard and jumper wires
- Power supply
- Cardboard lock box enclosure

# - Software

Programming Language: Arduino C++
Development Environment: Arduino IDE
Version Control: Git and GitHub

# How It Works (Roughly)

1) The RFID reader scans a card or tag.
2) The Arduino checks whether the card is authorized.
3) If authorized, the locking mechanism is activated.
4) The LCD displays the authentication result.
5) The system returns to its locked state after a specified interval.
